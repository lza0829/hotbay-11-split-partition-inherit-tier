# 热档片间（Hotbay）

影院素材分区温层：登记 → 冷热迁移 → 保留销毁 → 目录互证 → 拆号另立。

- 前端 http://127.0.0.1:6300
- API http://127.0.0.1:11300
- `docker compose up -d --build`

## 拆号另立口径

全局唯一架构：**新分区继承原分区现行温层与所属片库**。

- 新分区起始温层 = 原分区当前温层；归属片库 = 原分区所属片库，起始温层不由请求参数决定。
- 被拆素材段由原分区改挂新分区，湖对象键沿用并同步改为新分区所有，不新建目录行。
- 原分区仍有残留段则保持「在册」；一段不剩则关「已拆」。在册数不在两册间双加。
- 段改挂、在册变迁、拆号回执、对象键归属在同一写事务内同成败；异常整体回滚。
- 至少改挂一段，禁止只开新号；原分区有执行中迁移时拒绝拆号。
- 并发拆号以 `BEGIN IMMEDIATE` 串行化，避免同段双拆导致负段数或键双挂。

接口：`POST /api/拆号`、`GET /api/拆号`、`GET /api/拆号/{id}/改挂段`。
范围仅覆盖拆号另立的起始温层与段改挂守恒；跨库改挂、按件自标另立不在内。
